\# ShieldPix – AI Image Defense \& Anti-Deepfake Tool



ShieldPix is an AI image protection web application built with Python, PyTorch, and ResNet50. It applies an adversarial defense layer to photos to prevent unauthorized AI scrapers and deepfake models from extracting facial biometric features.



\## 🚀 Features

\- \*\*Biometric Protection:\*\* Blocks facial feature extraction by AI scrapers.

\- \*\*Visual Fidelity:\*\* Maintains HD image quality with 0.98+ SSIM score.

\- \*\*Interactive UI:\*\* Real-time protection level customization via Gradio.



\## 🛠️ Tech Stack

\- \*\*Languages:\*\* Python

\- \*\*Frameworks \& Libraries:\*\* PyTorch, Torchvision, Scikit-Learn, Gradio

\- \*\*Deployment:\*\* Hugging Face Spaces
